# VulnScope-AI
Beginner VAPT Portfolio Project

## Overview
A beginner-friendly web security assessment dashboard built with Python and Flask.

## Lab Environment
- Kali Linux
- Python and Flask
- OWASP Juice Shop
- Local target: http://127.0.0.1:3000

## Features
- HTTP status check
- Security header checks
- Basic cookie flag checks
- JSON evidence storage
- PDF report generation

## Sample Findings
- Missing Content-Security-Policy
- Missing Referrer-Policy
- HTTP instead of HTTPS

## Limitations
This project performs limited passive checks. Findings require review and are not proof of exploitability. Only assess systems you own or have permission to test.
